みたあと プライバシーポリシー

制定日: 2026年8月19日

当方は利用者の個人情報を収集しません。観た映画の記録(作品・日付・場所・一緒に観た人・評価・感想・写真)は、お使いの端末内にのみ保存されます。作品検索のときだけ、入力した検索語が当方の中継サーバーを経由して公開データベース(Wikidata)に送られますが、利用者を識別する情報は付けません。

本ポリシーは、CodeMedia(以下「当方」)が提供するアプリおよびウェブ版「みたあと」(以下「本アプリ」)における、利用者の情報の取り扱いについて定めるものです。

1. 収集する情報

当方は、本アプリを通じて利用者の個人情報を収集しません。アカウント登録は不要です。

具体的に、当方は以下をいずれも行いません。

  • 個人情報の収集・保存
  • 利用状況の解析(アクセス解析ツール等の組み込み)
  • 広告の配信、および広告目的のデータ利用
  • 位置情報、連絡先、カメラ、マイクへのアクセス
  • 端末識別子や広告 ID の取得
  • 利用者のデータを機械学習の学習用データとして利用すること

2. 利用者が入力したデータの取り扱い

本アプリでは、観た映画の作品名、観た日、映画館か配信かなどの場所、一緒に観た人の呼び名、星の評価、気分のタグ、感想、観たい映画、および任意で添付する半券・チケットの写真を利用者自身が入力します。これらのデータはお使いの端末内に保存され、当方に送信されることはありません。

iOS アプリではアプリ内のデータ領域(iCloud バックアップの対象)に、ウェブ版ではブラウザのローカルストレージに保存されます。アプリを削除(アンインストール)するか、ブラウザのサイトデータを消去すると、これらのデータも削除されます。設定画面からすべての記録を削除することもできます。

「一緒に観た人」は本人が特定できない呼び名(ニックネームや続柄)で入力することを推奨します。入力された内容は端末の外に出ませんが、端末を他者と共有している場合はご注意ください。

作品検索について

作品名を検索するとき、入力した検索語は当方が運用する中継サーバー(Cloudflare Workers)を経由して、公開データベース Wikidata(ウィキメディア財団、米国)の API に送信され、題名・公開年・監督名などの作品情報を取得します。この通信に利用者を識別する情報(氏名・メールアドレス・端末識別子など)は含まれず、当方は検索語を利用者と結びつけて保存しません。中継サーバーは同じ検索語に対する応答を一定期間キャッシュしますが、誰が検索したかの記録は持ちません。通信の過程で Cloudflare, Inc. および Wikimedia Foundation のサーバーにアクセスログ(IP アドレス等)が一般的な記録として残る場合があります。各社の取り扱いは、それぞれのプライバシーポリシーをご確認ください。検索を使わず、タイトルを手入力して記録することもできます。

写真について

半券やチケットの写真を記録に添える機能(iOS)は、利用者が「写真を追加」を選んだときにだけ写真ライブラリへのアクセスを求め、選ばれた1枚をアプリ内の保存領域にコピーします。写真が当方や第三者に送信されることはありません。記録を削除すると写真も削除されます。

共有機能について

年間のまとめを画像やテキストとして共有する機能があります。共有は利用者が「共有」を押したときにだけ、iOS の共有シートやブラウザの共有機能を通じて行われます。共有先での取り扱いは、共有先のサービスのポリシーに従います。当方が共有内容を受け取ることはありません。

App 内課金について

本アプリ(iOS)には「みたあと Pro」の買い切り課金があります。購入手続きは Apple の App Store が行い、当方が決済情報を受け取ることはありません。購入状態の確認は Apple のシステムを通じて行われ、当方のサーバーは介在しません。Apple による情報の取り扱いについては、Apple のプライバシーポリシーをご確認ください。

ウェブ版のホスティングについて

ウェブ版(mitaato.vercel.app)は Vercel Inc. のホスティングサービスで配信されています。ページの配信に伴い、同社のサーバーにアクセスログ(IP アドレス等)が記録される場合があります。これは配信基盤による一般的な記録であり、当方が利用者を識別する目的で参照・保存することはありません。ウェブ版に入力された記録がサーバーへ送信されることはありません。

3. 第三者への提供

当方は利用者の情報を収集しないため、第三者に提供、譲渡、販売することはありません。本アプリには外部の解析サービスや広告ネットワークを組み込んでいません。

4. お子様のプライバシー

本アプリは特定の年齢層を対象としたものではなく、いかなる年齢の利用者からも個人情報を収集しません。

5. データの安全管理

データは端末内に保存されるため、その安全性は端末自体のセキュリティ(画面ロック、OS の保護機能)に依存します。端末のロック機能の利用を推奨します。機種変更の際は、設定画面の「JSON を書き出す」でバックアップを取ることをおすすめします(写真は書き出しに含まれません)。

6. データの出典と免責事項

作品情報(題名・公開年・監督名など)は Wikidata(CC0)をもとにしています。作品によっては見つからない、または情報が不正確なことがあります。受賞作のリストは、各映画賞の公式発表および Wikipedia をもとに当方が作成した受賞事実(年・作品名・監督名)の一覧であり、各映画賞の主催者とは無関係です。賞の名称は受賞事実を記述するために用いており、賞のロゴ等は使用していません。

本アプリの利用によって生じた損害について、当方は責任を負いかねます。

7. 本ポリシーの変更

本ポリシーの内容は、法令の変更や本アプリの機能追加に応じて改定することがあります。重要な変更がある場合は、本ページにて告知します。
