推し相場 プライバシーポリシー

制定日: 2026年10月7日

当方は利用者の個人情報を収集しません。記録は、お使いの端末内にのみ保存されます。本アプリは通信を行いません。

本ポリシーは、CodeMedia(以下「当方」)が提供する iOS アプリ「推し相場」(以下「本アプリ」)における、利用者の情報の取り扱いについて定めるものです。

1. 収集する情報

当方は、本アプリを通じて利用者の個人情報を収集しません。アカウント登録は不要です。

具体的に、当方は以下をいずれも行いません。

  • 個人情報の収集・保存
  • 利用状況の解析(アクセス解析ツール等の組み込み)
  • 広告の配信、および広告目的のデータ利用
  • 位置情報、連絡先、カメラ、マイクへのアクセス、および写真ライブラリの読み取り
  • 端末識別子や広告 ID の取得
  • 利用者のデータを機械学習の学習用データとして利用すること

2. 利用者が作ったデータの取り扱い

本アプリに入力する「推しの呼び名・推し色・証券コード・上場日・上場時の株価」と、「材料(出来事の名前・強さ・日付・メモ)」、および設定(ガチホモード・株主の名前)、ならびに材料を入れた日時・殿堂入りの日時・説明を表示したかどうかの印など、アプリの動作に必要な情報は、お使いの端末内に保存され、当方に送信されることはありません。アプリを削除(アンインストール)すると、記録も削除されます。端末のバックアップ(iCloud バックアップなど)を取っている場合は、バックアップに含まれることがあります。

株価について

本アプリに表示される株価・証券コード・値動きは、利用者の入力から端末内で計算する架空の数字です。本物の株式・金銭・金融商品は一切扱いません。

画像の共有について

「推し相場新聞」「株券」「決算」の「画像で共有」を押すと、その画面の画像が端末内の一時領域に作られ、端末の共有シートが開きます。保存先や送信先は利用者が選びます。当方に画像が送られることはありません。共有シートで「画像を保存」を選んだときだけ、その画像が写真ライブラリに追加されます（初回に iOS が許可を確認します）。本アプリが写真ライブラリの中身を読み取ることはありません。

書き出しと読み込みについて

設定の「書き出す」を押すと、記録が JSON 形式のファイルになり、端末の共有シートが開きます。保存先や送信先は利用者が選びます。当方にファイルが送られることはありません。「読み込む」では、利用者が選んだファイルを本アプリが読み取ります。読み込みによって既存の記録が消えることはありません。

モーションセンサーについて

株券を表示しているとき(株券の画面と、上場のときに刷り上がる株券)は、端末を傾けたときにカードの傾き・光・浮かび上がる文字を動かすため、加速度センサーの値を読み取ります。値は画面の表示にだけ使い、保存も送信もしません。

広告と課金について

本アプリには広告も App 内課金もありません。

3. 第三者への提供

当方は利用者の情報を収集しないため、第三者に提供、譲渡、販売することはありません。本アプリには外部の解析サービスや広告ネットワークを組み込んでいません。

4. お子様のプライバシー

本アプリはいかなる年齢の利用者からも個人情報を収集しません。

5. データの安全管理

データは端末内に保存されるため、その安全性は端末自体のセキュリティ(画面ロック、OS の保護機能)に依存します。端末のロック機能の利用を推奨します。

6. 本ポリシーの変更

本ポリシーの内容は、法令の変更や本アプリの機能追加に応じて改定することがあります。重要な変更がある場合は、本ページにて告知します。
