そのひまで プライバシーポリシー

制定日: 2026年8月27日（最終更新: 2026年8月27日）

当方は利用者の個人情報を収集しません。書いた手紙の本文・添えた写真・誕生日や家族の情報は、お使いの端末内にのみ保存され、当方や第三者に送信されることはありません。手紙の内容を当方が読むことはできません。

本ポリシーは、CodeMedia(以下「当方」)が提供するアプリ「そのひまで」(以下「本アプリ」)における、利用者の情報の取り扱いについて定めるものです。

1. 収集する情報

当方は、本アプリを通じて利用者の個人情報を収集しません。アカウント登録は不要で、本アプリはサーバーを持たず、利用者の入力内容を外部に送信する通信を行いません。

具体的に、当方は以下をいずれも行いません。

  • 個人情報（手紙の本文・写真・誕生日・家族の情報を含む）の収集・保存
  • 利用状況の解析(アクセス解析ツール等の組み込み)
  • 広告の配信、および広告目的のデータ利用
  • 位置情報、連絡先、マイク、ヘルスケアデータへのアクセス
  • 端末識別子や広告 ID の取得
  • 利用者のデータを機械学習の学習用データとして利用すること

2. 利用者が入力したデータの取り扱い

本アプリでは、手紙の本文、宛名、開封日、添える写真、ご自身と家族の誕生日、便箋やロックなどの設定を利用者自身が入力します。これらはお使いの端末内に保存され、当方に送信されることはありません。アプリを削除(アンインストール)すると、これらの情報も削除されます。

「封をする」機能について

封をした手紙は、開封日まで本アプリの画面に表示されません。これは端末内での表示上の制御であり、暗号化による保護ではありません。手紙の本文は端末内のデータベースに保存されており、端末のバックアップにも含まれます。手紙を他人に読まれたくない場合は、本アプリのロック機能（Face ID / Touch ID / パスコード）と端末自体のパスコードをあわせてご利用ください。

誕生日と家族の情報について

「二十歳の誕生日」「成人式の朝」「◯◯が二十歳になる日」といった開封日を計算するために、ご自身や家族の誕生日を登録できます。登録は任意で、登録しなくても本アプリは利用できます。計算はすべて端末内で完結します。

写真について

手紙に写真を添えるときにのみ、写真ライブラリへのアクセス許可を求めます。選ばれた写真は本アプリの保存領域に複製され、端末内に保存されます。当方が写真を取得・閲覧することはありません。カメラとマイクは使用しません。

通知について

開封日の朝、その7日前、および年末の「あけおめカプセル」のお誘いをお知らせする機能があります。すべて端末内で作成・予約されるローカル通知であり、外部のサーバーを経由しません。通知の許可は任意で、許可しなくても本アプリの機能はすべて利用できます。通知の本文に手紙の中身は含まれません。

データの書き出しについて

設定画面から、手紙を含むすべてのデータをファイルに書き出せます。書き出したファイルには封をした手紙の本文も含まれます（バックアップのための機能のため）。書き出し先や共有先は利用者が選択します。当方に送信されることはありません。

アプリ内課金について

本アプリには買い切り型のアプリ内課金「そのひまでPro」があります。購入の処理と決済は Apple の App Store が行い、当方がクレジットカード番号などの決済情報を受け取ることはありません。購入状態の確認は Apple の仕組み（StoreKit）を通じて端末上で行います。

3. 第三者への提供

当方は利用者の情報を収集しないため、第三者に提供、譲渡、販売することはありません。本アプリには外部の解析サービスや広告ネットワークを組み込んでいません。

4. お子さまの利用について

本アプリは特定の年齢層を対象としたものではありませんが、個人情報を一切収集しないため、お子さまが利用する場合も情報が収集されることはありません。

5. 免責事項

本アプリの手紙は端末内にのみ保存されます。端末の故障・紛失・初期化、アプリの削除、バックアップの不備などにより手紙が失われる場合があります。長期間の保存を予定される場合は、端末のバックアップを有効にし、設定画面からのデータ書き出しもあわせてご利用ください。本アプリの利用によって生じた損害について、当方は責任を負いかねます。

開封日の通知は端末の状態（電源が入っていること、通知が許可されていること、アプリが削除されていないこと等）に依存します。通知が届かない場合でも、開封日を過ぎた手紙はアプリを開けばいつでも読めます。

6. 本ポリシーの変更

本ポリシーの内容は、法令の変更や本アプリの機能追加に応じて改定することがあります。重要な変更がある場合は、本ページにて告知します。
