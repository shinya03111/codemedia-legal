見たら仕分け プライバシーポリシー

制定日: 2026年10月19日・改定日: 2026年10月21日(アプリ名を「行く気半減期」から変更し、まとめて取り込み・埋め込みプレーヤーについて追記)

当方は利用者の個人情報を収集しません。送った・取り込んだ投稿のリンク、メモ・場所・分類、「行った」の記録は、お使いの端末内にのみ保存されます。

本ポリシーは、CodeMedia(以下「当方」)が提供する iOS アプリ「見たら仕分け」(以下「本アプリ」)における、利用者の情報の取り扱いについて定めるものです。

1. 収集する情報

当方は、本アプリを通じて利用者の個人情報を収集しません。アカウント登録・ログインはありません。当方のサーバーはなく、利用者の記録を当方が受け取ることはありません。

具体的に、当方は以下をいずれも行いません。

  • 個人情報の収集・保存
  • 利用状況の解析(アクセス解析ツール等の組み込み)
  • 広告の配信、および広告目的のデータ利用
  • 端末識別子や広告 ID の取得
  • 位置情報の取得(本アプリは位置情報の許可を求めません)
  • 通知の送信(本アプリは通知の許可を求めません)
  • 利用者のデータを機械学習の学習用データとして利用すること

2. 利用者が送った・入力したデータの取り扱い

本アプリでは、他のアプリの共有ボタンから送った投稿のリンク、まとめて取り込んだ投稿のリンク・日時・投稿者名、利用者が書いたメモ、利用者が選んだ場所・最寄り駅・分類、利用者が付けた分類の名前、「行った」の記録を扱います。これらはお使いの端末内に保存され、当方に送信されることはありません。

  • リンク: 共有した人を表しうる追跡用の文字列(例: utm_*、igsh、u_code など)を取り除いてから保存します。
  • 投稿の説明文: 共有のときに一緒に渡ってきた説明文は、分類と場所の候補を出すためにその場で読むだけで、保存しません。
  • 投稿日: リンクに含まれる投稿の番号から、端末の中で計算します(通信しません)。
  • 分類の候補: 説明文や投稿の題から分類の候補を出す処理は、端末の中の語の一覧だけで行います(外部に送りません)。
  • 風船のしぼみ方: 古い投稿の風船を少しずつしぼませる計算は、端末の中の記録だけで行います。

共有シートの拡張機能から本体のアプリへの受け渡しには、この端末の中だけで使うキーチェーンの領域を使います(iCloud キーチェーンや他の端末には移りません)。受け渡しが終わると、その領域からは削除します。

アプリを削除(アンインストール)すると、記録も削除されます。端末のバックアップ(iCloud バックアップなど)を取っている場合は、バックアップに含まれることがあります。設定画面の「書き出す」を使うと、記録を JSON ファイルとして取り出せます。送り先は利用者が共有シートで選んだアプリやサービスで、当方がそのファイルを受け取ることはありません。

3. まとめて取り込み

TikTok のお気に入りや Instagram の保存済みの投稿を取り込むときは、利用者が各サービスの公式の機能で自分でダウンロードしたデータのファイル(JSON)を、利用者が選んだときだけ、この端末の中だけで読みます。ファイルをどこかへ送ることはありません。読むのは保存した投稿のリンク・日時・投稿者名・コレクション名だけで、メッセージなどファイルに含まれるほかの情報は読まず、保存もしません。読み終えたファイルの中身は本アプリには残りません。各サービスへのログインは行いません。

4. 通信について

本アプリは、次の場面でだけ通信します。いずれも当方のサーバーではありません。

投稿の表示用の題・作者・サムネイル

送った投稿の題・作者・サムネイルを表示するために、その投稿のリンクを、投稿があるサービスの公開の埋め込み情報の窓口(TikTok・YouTube・X・Pinterest の oEmbed)に送るか、Apple の LinkPresentation フレームワークでそのページを読み込みます。取得した題・サムネイルは表示用の一時的なキャッシュで、期限が来ると消え、記録としては保存しません。動画や画像をダウンロードすることはありません。

仕分けタイムの埋め込みプレーヤー

仕分けタイムで利用者が「動画を見る」を押したときだけ、TikTok または YouTube の公式の埋め込みプレーヤーを読み込みます。このとき、利用者の端末から各サービスに接続し、各サービスのプライバシーポリシーが適用されます。本アプリはこの表示のための閲覧の記録(クッキーなど)を端末に残さない設定で表示します。

場所の検索と電車の所要時間

場所を探すとき、最寄り駅や家の駅からの電車の所要時間を出すときに、Apple のマップの機能(MapKit)を使います。このとき検索した言葉や場所の座標が Apple に送られます。Apple による取り扱いは Apple のプライバシーポリシーに従います。

App 内課金

「仕分けパス」の購入と復元は、Apple の App Store を通じて行われます。当方が支払い情報を受け取ることはありません。

5. 写真

「行った」風船に写真を入れるときは、利用者が写真の選択画面で選んだ1枚だけを読み込みます(写真ライブラリ全体へのアクセスは求めません)。取り込むときに縮小し、撮影場所などの情報を取り除いてアプリ内に保存します。今月の空などの画像を「写真に保存」するときだけ、写真への追加の許可を求めることがあります。

本アプリは、年齢を問わずお使いいただけます。当方は年齢にかかわらず個人情報を収集しません。
