ひといろ プライバシーポリシー

制定日: 2026年8月25日

当方は利用者の個人情報を収集しません。気分の記録(選んだ色・ひとことメモ)は、お使いの端末内にのみ保存されます。

本ポリシーは、CodeMedia(以下「当方」)が提供する iOS アプリおよびウェブアプリ「ひといろ」(以下「本アプリ」)における、利用者の情報の取り扱いについて定めるものです。

1. 収集する情報

当方は、本アプリを通じて利用者の個人情報その他の情報を一切収集しません。

  • アカウント登録・ログインは不要で、その仕組み自体がありません
  • アクセス解析・トラッキング(計測 SDK 等)は行いません
  • 広告は表示しません(広告 SDK も組み込んでいません)
  • 端末識別子や広告 ID の取得も行いません

2. データの保存場所

本アプリで記録した内容(日付ごとの気分の段階・ひとことメモ・表示設定)は、すべて利用者の端末内のストレージにのみ保存されます。当方を含む外部のサーバーへ送信されることはなく、当方がこれらのデータにアクセスすることもできません。

iOS 版では、端末のバックアップ(iCloud バックアップ等)に記録が含まれることがあります。これは OS の標準機能によるもので、当方がその内容にアクセスすることはできません。

ウェブ版をご利用の場合も同様に、記録はブラウザ内のストレージにのみ保存されます。ブラウザのデータを消去すると記録も削除されます。

3. 通知について

記録を忘れないためのリマインダーとして、端末のローカル通知を使用できます。通知は端末内で完結し、当方のサーバーを経由しません。通知の許可は任意で、拒否した場合でも記録機能はすべて利用できます。

4. Face ID / Touch ID について

アプリのロック機能を有効にした場合、本人確認のために OS の生体認証(Face ID / Touch ID)を使用します。認証は端末内で完結し、生体情報が本アプリや当方に渡ることはありません。

5. アプリ内課金について

買い切りの「ひといろ+」の購入は、Apple の App Store の仕組みを通じて行われます。決済は Apple が処理し、当方がクレジットカード情報等を取得することはありません。購入状態(購入済みかどうか)のみを端末内に保存します。

6. データの書き出しと削除

記録は設定画面から JSON ファイルとして書き出せます。書き出し先や送信先は利用者が選択します。また、作成した「一年の一枚」などの画像の共有先も利用者が選択します。

個々の記録は、アプリ内から塗り直し・削除できます。本アプリを端末から削除すると、保存されていた記録もすべて削除されます。当方の側にデータは残りません。

7. 第三者への提供

当方が利用者の情報を保有しないため、第三者への提供・共有・販売は一切行いません。

8. ポリシーの変更

本ポリシーの内容を変更する場合は、本ページで告知します。重要な変更がある場合は、アプリのアップデート情報等でもお知らせします。

English summary

Hitoiro does not collect any personal information. All records (daily mood level and optional notes) are stored only on your device and are never transmitted to us or any third party. There are no accounts, no analytics, and no ads.

Optional local notifications and Face ID app lock are processed entirely on-device. The one-time in-app purchase is handled by Apple; we never receive your payment details. Deleting the app removes all stored data.

Questions: codemedia.app@gmail.com (CodeMedia).
