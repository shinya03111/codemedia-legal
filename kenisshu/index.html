県一周レース プライバシーポリシー

制定日: 2026年10月14日

当方は利用者の個人情報を収集しません。当方のサーバーはありません。記録・車・ナンバーの設定は、お使いの端末の中に保存されます。全国の順位は、Apple の Game Center を使って読み書きします。

本ポリシーは、CodeMedia(以下「当方」)が提供する iOS アプリ「県一周レース」(以下「本アプリ」)における、利用者の情報の取り扱いについて定めるものです。

1. 収集する情報

当方は、本アプリを通じて利用者の個人情報を収集しません。アカウント登録はありません。当方が運営するサーバーは無く、本アプリが通信するのは、Apple の Game Center(順位の読み書き)と App Store(購入の手続き)だけです。

具体的に、当方は以下をいずれも行いません。

  • 個人情報(お名前、年齢、メールアドレスなど)の収集・保存
  • 利用状況の解析(アクセス解析ツール等の組み込み)
  • 広告の配信、および広告目的のデータ利用
  • カメラ、マイク、位置情報、連絡先、写真、ヘルスケアのデータへのアクセス
  • 端末識別子や広告 ID の取得
  • 利用者のデータを機械学習の学習用データとして利用すること

本アプリに、文字を自由に入力する欄はありません。「自分の県」は、ナンバープレートの表示とランキングの集計のために選ぶもので、出身地・居住地を確かめるものではありません(好きな県を選べます)。位置情報は使いません。

2. 端末の中に保存する情報

以下はお使いの端末内に保存され、当方に送信されることはありません。

  • 選んだ「自分の県」、車のかたちと色、ナンバープレート(地名・ひらがな・番号・色と柄)
  • 県ごとの記録(ベストのタイム、メダル、走った回数、直近の記録、ベストのときの走り)
  • 持っている地名、交付くじの券の枚数、券と交換した色
  • 設定(カーナビの声・効果音・振動のオン/オフ、空と光を時刻に合わせるかどうか)

アプリを削除(アンインストール)すると、これらも削除されます。端末のバックアップ(iCloud バックアップなど)を取っている場合は、バックアップに含まれることがあります。

Game Center(全国の順位)について

Game Center にサインインしているときだけ、コースを走りきるたびに、その記録を Apple の Game Center に送ります(サインインする前に走った記録は、アプリを開いたままサインインしたときに送ります)。送るのは次の2つです。

  • その県を一周したタイム
  • 記録に添える小さな札: 選んだ「自分の県」、ナンバープレートの地名・ひらがな・番号・色と柄、車のかたちと色、区間ごとのタイムの配分

これらは、同じランキングを見るほかの利用者に表示されます。本アプリの画面では、県名とナンバープレートだけを表示し、Game Center のニックネームは表示しません(Apple の Game Center の画面では、ニックネームとともに表示されます)。Game Center のアカウントと記録は Apple が取り扱い、当方が受け取ったり保存したりすることはありません。Game Center にサインインしなくても、すべてのコースを遊べます。

ナンバープレートについて

本アプリのナンバープレートは架空のものです。地名は実在の地域名ですが、ひらがなは実際のナンバープレートでは使われない「お・し・へ・ん」だけを使っているため、実在の車両の番号と同じになることはありません。

App内課金(全国周遊パス)について

「全国周遊パス」は、1回かぎりの買い切りです(自動で更新される課金ではありません)。購入は Apple の App Store を通じて行われます。お支払いに関する情報は Apple が取り扱い、当方が受け取ることはありません。購入が有効かどうかは、端末が App Store に問い合わせて確かめます。

カーナビの声について

カーナビの声は、iPhone に入っている読み上げの機能を使って端末の中で作ります。音声が外部に送られることはありません。

広告について

本アプリに広告はありません。

3. 第三者への提供

当方は利用者の情報を収集しないため、第三者に提供、譲渡、販売することはありません。本アプリには外部の解析サービスや広告ネットワークを組み込んでいません。

4. お子さまのプライバシー

本アプリは、いかなる年齢の利用者からも個人情報を収集しません。

5. データの安全管理

データは端末内に保存されるため、その安全性は端末自体のセキュリティ(画面ロック、OS の保護機能)に依存します。

6. 本ポリシーの変更

本ポリシーの内容は、法令の変更や本アプリの機能追加に応じて改定することがあります。重要な変更がある場合は、本ページにて告知します。
