みっかもどし プライバシーポリシー

制定日: 2026年9月30日

当方は利用者の個人情報を収集しません。記録は、お使いの端末内にのみ保存されます。本アプリは通信を行いません。

本ポリシーは、CodeMedia(以下「当方」)が提供する iOS アプリ「みっかもどし」(以下「本アプリ」)における、利用者の情報の取り扱いについて定めるものです。

1. 収集する情報

当方は、本アプリを通じて利用者の個人情報を収集しません。アカウント登録は不要です。

具体的に、当方は以下をいずれも行いません。

  • 個人情報の収集・保存
  • 利用状況の解析(アクセス解析ツール等の組み込み)
  • 広告の配信、および広告目的のデータ利用
  • 位置情報、連絡先、写真、カメラ、マイクへのアクセス
  • 端末識別子や広告 ID の取得
  • 利用者のデータを機械学習の学習用データとして利用すること

2. 利用者が作ったデータの取り扱い

本アプリに記録する「食べすぎた日」の日付ときっかけ、および3日間の行動の記録は、お使いの端末内に保存され、当方に送信されることはありません。アプリを削除(アンインストール)すると、記録も削除されます。端末のバックアップ(iCloud バックアップなど)を取っている場合は、バックアップに含まれることがあります。

本アプリが記録しないもの

本アプリは、体重・体脂肪率・カロリー・食事の内容・写真を記録する機能を持ちません。これらの入力欄はアプリ内に存在しません。

書き出しと読み込みについて

「書き出す」を押すと、記録が JSON 形式のファイルになり、端末の共有シートが開きます。保存先や送信先は利用者が選びます。当方にファイルが送られることはありません。「読み込む」では、利用者が選んだファイルを本アプリが読み取ります。読み込みによって既存の記録が消えることはありません。

通知について

本アプリの通知は、端末内で予定を組み立てて表示するローカル通知のみです。通知のために当方のサーバーや外部サービスと通信することはなく、通知用の識別子(プッシュトークン)を取得することもありません。通知は端末の設定でいつでもオフにできます。

広告と課金について

本アプリには広告も App 内課金もありません。

3. 第三者への提供

当方は利用者の情報を収集しないため、第三者に提供、譲渡、販売することはありません。本アプリには外部の解析サービスや広告ネットワークを組み込んでいません。

4. お子様のプライバシー

本アプリはいかなる年齢の利用者からも個人情報を収集しません。

5. データの安全管理

データは端末内に保存されるため、その安全性は端末自体のセキュリティ(画面ロック、OS の保護機能)に依存します。端末のロック機能の利用を推奨します。

6. 本ポリシーの変更

本ポリシーの内容は、法令の変更や本アプリの機能追加に応じて改定することがあります。重要な変更がある場合は、本ページにて告知します。
