おかん天気 プライバシーポリシー

制定日: 2026年8月12日 / 改定日: 2026年11月3日

当方は、お問い合わせのメールを除いて、利用者の個人情報を受け取りません。位置情報も取得しません。選んだ地点や設定、手帳の記録は、お使いの端末内にのみ保存されます。

本ポリシーは、CodeMedia(以下「当方」)が提供するアプリおよびウェブ版「おかん天気」(以下「本アプリ」)における、利用者の情報の取り扱いについて定めるものです。

1. 収集する情報

当方は、本アプリを通じて利用者の個人情報を収集しません。アカウント登録は不要です。利用者がご自身でお問い合わせのメールを送った場合に限り、当方はそのメールの内容とメールアドレスを受け取ります(下記「お問い合わせのメールについて」)。

具体的に、当方は以下をいずれも行いません。

  • お問い合わせのメールを除く、個人情報の収集・保存
  • 利用状況の解析(アクセス解析ツール等の組み込み)
  • 広告の配信、および広告目的のデータ利用
  • 位置情報、連絡先、カメラ、マイクへのアクセス
  • 端末識別子や広告 ID の取得
  • 利用者のデータを機械学習の学習用データとして利用すること

本アプリは天気を表示するアプリですが、現在地の取得は行いません。表示する地点は、利用者が一覧から選んだ市区町村だけです。

2. 利用者が設定したデータの取り扱い

本アプリでは、表示する拠点(複数登録できます)、おかんの口うるささ、朝の通知の有無と時刻、効果音・BGM・振動の有無を利用者自身が設定します。また、「おかんの手帳」を表示するために、アプリを開いた日、聞いたセリフ、その日の天気の記録を端末内に残します。これらはお使いの端末内に保存され、当方に送信されることはありません。アプリを削除(アンインストール)するか、ブラウザのサイトデータを消去すると、これらも削除されます。

通知について

本アプリ(iOS)は、朝に天気と服装・傘の目安をお知らせする機能を備えています。通知は端末内で作成・予約されるローカル通知であり、外部のサーバーを経由しません。朝の通知は、拠点の一覧のいちばん上の地点で作成します。通知の許可は任意で、端末の設定からいつでも変更できます。

ウィジェットについて

ウィジェットは、ウィジェットごとに選んだ地点の予報を気象庁から取得して表示します。アプリ本体とのデータのやりとりはなく、外部へ利用者の情報を送信することもありません。

お問い合わせのメールについて

アプリの「ひとこと送る」は、お使いのメールアプリを開くものです。利用者が送信するまで、何も送られません。本文にはアプリのバージョンと iOS のバージョンがあらかじめ入ります(送信前に消せます)。端末名や地点は入りません。お送りいただいた内容とメールアドレスは、返信と本アプリの改善のためにのみ利用し、第三者に提供しません。

3. 気象データの取得について

本アプリが表示する天気予報・降水確率・気温・警報と注意報・警報級の可能性・天気概況・台風情報は、気象庁が公開しているデータを取得して表示しています(出典: 気象庁ホームページ)。

iOS アプリでは、登録した拠点の予報を取得するために、気象庁のサーバーへ通信します。この通信で送信されるのは予報区のコードのみで、利用者を識別する情報は含まれません。ウェブ版では、当方のサーバーが取得したデータをキャッシュして配信するため、利用者の端末から気象庁へ直接通信することはありません。

ウェブ版のホスティングについて

ウェブ版は Vercel Inc. のホスティングサービスで配信されています。ページの配信に伴い、同社のサーバーにアクセスログ(IP アドレス等)が記録される場合があります。これは配信基盤による一般的な記録であり、当方が利用者を識別する目的で参照・保存することはありません。

4. 第三者への提供

当方は利用者の情報を第三者に提供、譲渡、販売することはありません。本アプリには外部の解析サービスや広告ネットワークを組み込んでいません。

5. お子さまの利用について

本アプリは特定の年齢層を対象としたものではありません。アプリの利用だけで個人情報が収集されることはありません。

6. 免責事項

本アプリが表示する天気予報は気象庁の発表をそのまま表示するものであり、当方が独自に予報を行うものではありません。台風の地図は気象庁の発表の図形をそのまま描いたものであり、当方が距離や到達時刻を計算したものではありません。キャラクター(おかん)のセリフは、気象庁の発表内容にもとづく生活上の目安であって、気象庁の発表そのものではありません。服装・傘・洗濯などの提案は目安であり、実際の判断は利用者ご自身で行ってください。災害時の行動は、気象庁および自治体が発表する情報に必ず従ってください。本アプリの利用によって生じた損害について、当方は責任を負いかねます。

本ポリシーの内容は、法令の変更や本アプリの機能追加に応じて改定することがあります。重要な変更がある場合は、本ページにて告知します。
